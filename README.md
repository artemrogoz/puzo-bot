# Пузомер — Telegram-бот

Команды: /start, /program, /waist 95, /stats, /tip

## Запуск
1. Получи токен у @BotFather
2. `pip install -r requirements.txt`
3. `export BOT_TOKEN="токен"` (Windows: `set BOT_TOKEN=токен`)
4. `python puzo_bot.py`

## Деплой (Railway / Render)
- Подключи этот репозиторий
- Тип сервиса: Worker (команда запуска: `python puzo_bot.py`)
- В Variables добавь `BOT_TOKEN`

Токен НЕ хранить в коде и не заливать на GitHub.
